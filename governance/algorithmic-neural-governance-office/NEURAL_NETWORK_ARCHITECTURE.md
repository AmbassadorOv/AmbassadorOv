## Core thesis

The Institute proposes a dedicated **Algorithmic & Neural Governance Office (ANGO)** as a distinct architectural department for the governance, evidence, verification and lifecycle analysis of algorithmic and neural computational systems.

This is a proposed Institute innovation. A claim that no government anywhere has an equivalent structure requires a completed comparative institutional survey and is therefore not asserted as a verified fact here.

## Academic family tree

Academic sources are routed as first-class research nodes:

```
Research Institution
  -> Laboratory / Research Group
  -> Researcher / Author
  -> Paper / Dataset / Code
  -> Method / Architecture
  -> Neural Family
  -> ANGO
  -> Vitruvius
```

A researcher is represented as a **research attribution node**, not as a Git branch and not as a claim of participation in the Institute.

Where a public GitHub organization/repository is available, the repository becomes the technical source node. Publications, author identities and institutional affiliations require separate evidence before being linked.

## Routing principle

Each discovered source receives:

```
Source
  -> Institution
  -> Domain
  -> Neural / Algorithmic Family
  -> Thought / Capability Family
  -> Institute Office
  -> Vitruvius Node
  -> Global Root
  -> WANGA Main Bridge
```

Many-to-many routing is allowed. A repository can belong to several architecture families and several offices.

## Intended role in the new computer

The proposed computer is built around the principle:

**Computation produces capability; neural systems produce inference; Rational Logic structures reasoning; evidence establishes provenance; verification establishes trust; governance establishes authorization; Vitruvius establishes architectural awareness.**

ANGO is therefore the dedicated interface that makes the neural computational world measurable and governable without claiming control over external institutions or systems.
