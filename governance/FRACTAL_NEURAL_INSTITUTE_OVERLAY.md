# Fractal Neural Architecture Overlay — Institute

Status: SPECIFIED

This layer wraps the Institute's proposed architecture without claiming that it constitutes a government or governmental authority. It is a technical architecture for organizing research, offices, branches, evidence, dependencies and Vitruvius mappings.

## Fractal rule

Every architectural family is recursively mapped:

`Institute → Office → Architecture Family → Subfamily → Component → Git Branch → Evidence → Vitruvius Node → Parent Vitruvius → WANGA Vitruvius Main Bridge`

The overlay is many-to-many: an existing branch may participate in several architectural families when its scope overlaps. No branch is treated as proof of implementation merely because it is connected.

## Coverage target

The current branch set is the first layer. The overlay is designed to continue recursively until all discoverable architecture families and suitable branches are mapped. Unmatched areas remain explicitly UNKNOWN/UNASSIGNED rather than being fabricated.

## Vitruvius hierarchy

Office Vitruvius nodes → Vitruvius Global Root → WANGA Vitruvius Main Bridge.

Vitruvius performs architecture mapping, lineage/dependency analysis and evidence-gap detection. It does not create institutional, governmental, financial or regulatory authority.

## Research boundary

The Institute is an institute/research architecture. Terms such as global, governance, office and branch manager describe the proposed software/institutional model only; they do not assert an actual government, regulator, central bank, legal tender, jurisdiction or public authority.
