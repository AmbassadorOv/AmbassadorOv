# CODEX MAP — AmbassadorOv / WANGA Ecosystem

## Purpose
The Codex is the navigation and provenance layer for the repository ecosystem.
Code is not the map. The Codex maps where code, models, sources, datasets, experiments, evidence and governance rules live.

## Master chain
MASTER CODEX → REPOSITORY CODEX → DOMAIN CODEX → SOURCE / DATASET → IMPLEMENTATION → TEST / EVIDENCE → STATUS

## Mandatory local Codex schema
repository, codex_id, role, domain, status, sources, projects, models, datasets, tests, evidence, dependencies, forbidden_imports, open_questions.

## Non-negotiable rules
1. A repeated reference does not become a new source.
2. A source is never replaced by a summary.
3. Similarity does not establish lineage.
4. Inference does not become fact without evidence.
5. Code does not establish historical truth.
6. Philosophy is not a substitute for operational specification.
7. Every important claim needs provenance.
8. Every project needs a stable ID.
9. Every cross-repository dependency must be explicit.
10. Every active repository needs a Codex entry.
11. The Master Codex points to local Codices; it does not duplicate whole repositories.
12. UNKNOWN remains UNKNOWN until evidence changes the status.
