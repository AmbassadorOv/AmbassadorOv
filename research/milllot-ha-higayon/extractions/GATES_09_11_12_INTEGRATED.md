# מילות ההגיון — שערים ט, יא, יב — שכבת החילוץ המשולבת

**מקור:** Sivan22/otzaria-library / אוצריא/מחשבת ישראל/ראשונים/מילות הגיון.txt  
**סטטוס:** SOURCE_EXTRACTED  
**כלל:** אין כאן משפטים מומצאים. כל פריט הוא משפט מקור או יחס שניתן ישירות מן המשפטים שכבר חולצו.

## שער ט — הסבות

### יחסים ישירים
- ארבע הסבות → החומר / הצורה / הפועל / התכלית.
- החומר / הצורה / הפועל / התכלית → מבארות נראים בעניינים המלאכתיים.
- בעניינים הטבעיים → ראוי שנבקש בהן אלו הסבות בעצמן.
- הפועל הקרוב → האבן.
- הפועל הרחוק → עלית האד.
- החומר הקרוב של ראובן → איברי הגוף.
- החומר הרחוק של ראובן → הלחות וארבעה היסודות.
- ארבעת היסודות → מים / אויר / אש / ארץ.
- הדבר המשותף לארבעת היסודות → החומר הראשון.
- החומר הראשון → היולי.
- חומר הגלגלים → חומר פשוט.
- כלל השמות בשער ט → עשרה.

## שער יא — עצמות, מקרה, בכח, בפועל, הפכים, קנין והעדר, הצטרפות

### יחסים ישירים
- מה שנמצא לדבר־מה → בעצמות.
- מה שמציאותו על המעט → במקרה.
- תואר הנמצא בדבר בעת תיאורו → בפועל.
- תואר שאינו נמצא עתה אך מוכן להגיע → בכח.
- הכח → קרוב / רחוק.
- חום וקור → הפכים שביניהם אמצעי.
- זוג ונפרד → הפכים שאין ביניהם אמצעי.
- ראות → קנין.
- עורון → העדר.
- חכמה → קנין.
- סכלות → העדר הקנין.
- ארוך וקצר → מצטרפים.
- היחס בין ארוך וקצר → הצטרפות.
- נער ראובן / פתח הבית → נוטה.
- כלל השמות בשער יא → ששה עשר.

### הבחנה מרכזית
המקור מבחין במפורש בין:
- **הפכים** — שני הצדדים הם במציאות.
- **קנין והעדר** — צד אחד הוא מציאות הקנין והצד האחר הוא העדרו.

## שער יב — קדימה ויחד

### יחסים ישירים
- קדימה → חמשה פנים.
- קדימה בזמן → קדם לאברהם.
- קדימה בטבע → החי קודם לאדם בטבע.
- קדימה במדרגה → קרוב יותר לשלטון.
- קדימה במעלה → היותר שלם / הנכבד יותר.
- קדימה בסבה → הסבה קודמת למסובב.
- יחד בזמן → נמצאים בעת אחת.
- יחד במקום → נמצאים במקום אחד.
- יחד במדרגה → מרחק שווה מהתחלה אחת.
- יחד בטבע → שני דברים המסתפקים בחיוב המציאות ואחד אינו סבה לאחר.
- הסמוכים → יחד מצד הסמיכות.
- כלל השמות בשער יב → תשעה.

## מה נכנס לשלב הבא

1. **שער ט** מספק את מבנה הסבה: חומר / צורה / פועל / תכלית, ובתוך הפועל והחומר — קרוב / רחוק.
2. **שער יא** מספק הבחנות לוגיות על אופן הימצאות התואר: בעצמות / במקרה; בפועל / בכח; וכן הפכים / קנין והעדר / הצטרפות.
3. **שער יב** מספק את ציר היחס: קודם / יחד, עם חמש צורות קדימה וארבע צורות יחד.
4. אין להסיק מכאן שמונח מסוים הוא אחד מששת סוגי השמות המשותפים של שער יג. השיוך לשער יג ייעשה רק כאשר מקור שער יג מגדיר אותו כך.
5. אין להוסיף סיווג חדש שאינו מופיע במקור או במערכת המשפטים שכבר הוגדרה בשערים א–ח.
