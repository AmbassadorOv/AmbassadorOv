# BUNDLE 01A — שער א׳ — המשפטים שהמקור עצמו מביא כדוגמאות

**Rule:** כאן לא מנתחים רק את משפטי ההסבר. מחלצים בנפרד את המשפטים שהרמב"ם עצמו מכניס בתוך המשפטים שלו כדוגמאות, ומפרקים אותם.

## EXAMPLE 001
> ראובן עומד

- סוג: משפט חיובי
- נושא: ראובן
- נשוא: עומד
- חלקים: [ראובן] + [עומד]
- יחס: נושא → נשוא
- תבנית: [נושא] + [נשוא]

## EXAMPLE 002
> ראובן בלתי עומד

- סוג: משפט שלילי
- נושא: ראובן
- נשוא: בלתי עומד
- חלקים: [ראובן] + [בלתי עומד]
- יחס: נושא → נשוא בשלילה
- תבנית: [נושא] + [נשוא שלילי]

## EXAMPLE 003
> ראובן עמד או יעמוד

- סוג: משפט עם נשוא מורכב/חלופי
- נושא: ראובן
- נשוא: עמד או יעמוד
- חלקים: [ראובן] + [עמד או יעמוד]
- יחס: נושא → נשוא
- תבנית: [נושא] + [נשוא מורכב]

## EXAMPLE 004
> ראובן בבית

- סוג: משפט שבו המקור מגדיר את "בבית" כנשוא
- נושא: ראובן
- נשוא: בבית
- חלקים: [ראובן] + [בבית]
- יחס: נושא → נשוא
- תבנית: [נושא] + [ביטוי נשואי]

## EXAMPLE 005
> ראובן העברי אשר היה עומד בבית שמעון הרג בנו של לבן הארמי

- סוג: משפט מרובה מילים
- נושא: ראובן העברי אשר היה עומד בבית שמעון
- נשוא: הרג בנו של לבן הארמי
- חלקים:
  - נושא מורחב: [ראובן העברי אשר היה עומד בבית שמעון]
  - נשוא מורחב: [הרג בנו של לבן הארמי]
- יחס: נושא → נשוא
- תבנית: [נושא מורחב] + [נשוא מורחב]

## SOURCE LINKAGE

כל חמשת המשפטים הם **EXAMPLE_SENTENCE**, כלומר משפטים המובאים בתוך משפטי המקור בשער א׳.

הם אינם משפטים חדשים שנוצרו על ידי המערכת.

## מה נעשה מכאן

בכל שער:
1. מחלצים את משפטי ההסבר של הרמב"ם.
2. מתוך כל משפט הסבר מחלצים את המשפטים שהוא מביא כדוגמה.
3. כל דוגמה מקבלת מספר עצמאי.
4. מפרקים אותה לנושא / נשוא / חלקים / יחס.
5. רק לאחר מכן מפיקים תבנית.
6. לא מערבבים SOURCE עם DERIVED.
