## Important ownership rule

A fork is preserved as **research input / supporting infrastructure**, not presented as original authorship of the upstream project.

A historical repository is preserved as **lineage**, not automatically upgraded to a current research claim.

A minimal or empty repository is retained as a historical pointer and does not receive a stronger status without evidence.
