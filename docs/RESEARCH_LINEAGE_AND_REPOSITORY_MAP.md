## Corpus rules

**Canonical research** = current research owner and public source of truth.

**Supporting** = infrastructure or external software useful to the research system but not represented as original authorship.

**Historical** = evidence of research lineage or experimentation; not automatically a current claim.

**Unclassified / low-evidence** = retained until a later audit establishes a stronger classification.

**Fork** = source code inherited from an upstream repository and therefore not attributed as original implementation.
