# Vitruvius Dual-Engine Architecture

Status: SPECIFIED

## Purpose
A dedicated Vitruvius architecture-intelligence layer for the WANGA Digital Intelligence Engine and Industrial Execution Engine.

## Scope
Vitruvius maps, classifies and connects architecture families across both engines without granting execution authority.

### Digital Intelligence Engine
Compute → Model Fabric → Digital Model Agents → NTM → Rational Logic → Decision Candidate

### Industrial Execution Engine
Capital/Energy/Materials → Machines/Infrastructure → Operations → Organizations → Production/Services → Physical/Economic Consequence

## Cross-engine Vitruvius functions
1. Discover architecture components and dependencies.
2. Normalize heterogeneous architecture descriptions.
3. Classify components into architecture families.
4. Build dependency and interface graphs.
5. Identify evidence, provenance and verification boundaries.
6. Detect integration candidates and missing evidence.
7. Emit architecture maps for WANGA verification and governance.

## Safety boundary
Vitruvius is an architecture-intelligence and mapping layer. It does not itself authorize consequential actions, certify systems, or claim live integration.

## Interfaces
- Input: repository metadata, architecture manifests, component metadata, evidence references.
- Output: architecture graph, family classification, dependency map, integration candidates, evidence requirements.
- WANGA boundary: Evidence/Provenance → Verification → Drift Forensics → Policy/Authorization → Integration & Deployment.
