# Vitruvius Model Lineage

Status: SPECIFIED

Tracks where a model/agent architecture originates, which parent architecture produced or configured it, which transformations occurred, and which descendants inherit or derive from it.

## Graph
Origin → Parent Architecture → Model/Agent → Variant → Deployment → Descendants

Vitruvius records lineage as architecture metadata and evidence references; it does not infer legal ownership or authorship from lineage alone.
