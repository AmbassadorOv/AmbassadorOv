# WANGA Institutional Architecture Library

This directory is the architecture library for the proposed Global Algorithmic Governance ecosystem.

## Architecture branches

- agent/wanga/engine-digital — Digital Economic Engine
- agent/wanga/engine-industrial — Industrial Economic Engine
- agent/wanga/engine-verification — Verification / Evidence / Governance boundary
- agent/wanga/engine-models — Model deployment profile
- agent/wanga/engine-agents — Agent deployment profile
- agent/wanga/engine-organizations — Organization deployment profile
- agent/wanga/engine-industries — Industry deployment profile
- agent/wanga/engine-finance-insurance-property — Insurance / Banking / Property Evidence profile
- agent/wanga/vitruvius-governance — Vitruvius architecture intelligence and governance mapping

## Shared architectural spine

Digital Engine
→ WANGA Verification Boundary
→ Industrial Engine

Vitruvius is a cross-cutting architecture intelligence layer. Its role is to map the computational topology across models, agents, organizations, industries and institutional systems, rather than being limited to the 5,000-repository research corpus.

## Five deployment profiles

Models → Agents → Organizations → Industries → Insurance/Banking/Property Evidence

Each branch is an implementation workspace. Branch creation does not mean that the corresponding subsystem is built or verified.
