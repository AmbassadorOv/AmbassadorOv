# Vitruvius ↔ WANGA Main Bridge

Status: SPECIFIED

## Purpose
Connect the dedicated Vitruvius Dual-Engine layer back to the main WANGA architecture while preserving authority boundaries.

## Topology
WANGA Main
→ Global Work Manager / WANGA OS
→ Model Fabric / DMA / NTM / Rational Logic
→ Evidence & Provenance
→ Verification / Drift Forensics
→ Vitruvius Dual-Engine Mapper
→ Architecture Graph / Dependency Graph / Integration Candidates
→ Policy & Authorization
→ Integration & Deployment

Vitruvius may observe and map the architecture of the two engines and return structured architecture intelligence to WANGA. It does not bypass WANGA verification or authorization gates.

## Bidirectional interface
- WANGA → Vitruvius: canonical architecture manifests, component metadata, evidence references, verification state.
- Vitruvius → WANGA: normalized architecture graph, dependency relationships, family classifications, candidate integration points, detected evidence gaps.

## Global governance boundary
This bridge is designed as a technical interface for future institutional/governance architecture layers. It does not establish governmental authority, institutional legal status, certification authority, or live external integrations.
